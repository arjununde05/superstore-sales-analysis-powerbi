# Superstore Sales & Profit Analysis Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive Power BI dashboard developed to analyze Superstore sales and profitability data.

The dashboard provides a business-focused view of sales performance across different categories, sub-categories, products, regions, states, customer segments, and time periods.

The project demonstrates practical skills in data cleaning, data modeling, DAX, data visualization, dashboard development, and business analysis.

---

## 🎯 Business Objective

The main objective of this project is to analyze sales and profit performance and identify important patterns in the business data.

The dashboard helps answer questions such as:

* What is the total sales and profit?
* How are sales changing over time?
* Which categories and sub-categories generate the most sales?
* Which products contribute the most to profit?
* Which regions and states perform better?
* Which customer segments generate higher sales?
* Where are losses or low-profit areas occurring?
* How does discounting affect profitability?

## 🔄 Project Workflow

### 1. Data Collection

The Superstore dataset was imported into Power BI for analysis.

### 2. Data Cleaning

The dataset was prepared using Power Query.

The preparation process included:

* Checking data types
* Handling missing values where required
* Removing unnecessary columns
* Formatting date fields
* Checking duplicate records
* Preparing fields for analysis

### 3. Data Transformation

The data was transformed into an analysis-ready structure using Power Query.

### 4. Data Modeling

Relationships between relevant tables/fields were created to support dashboard analysis.

The data model was designed to allow filtering and interaction across different dimensions such as:

* Date
* Product
* Customer
* Category
* Region

### 5. DAX Measures

DAX measures were created to calculate important business KPIs such as:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Profit Margin
* Average Sales

### 6. Dashboard Development

Interactive Power BI visuals were created to analyze:

* Sales performance
* Profit performance
* Category performance
* Sub-category performance
* Regional performance
* Customer segments
* Product performance
* Monthly and yearly trends

### 7. Analysis

The dashboard was used to identify sales trends, profitable categories, regional performance, customer behavior, and areas requiring further investigation.
